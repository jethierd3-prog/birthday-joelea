# Joelea's Birthday Garden 💜

Files (all in the same folder, so paths work on GitHub Pages):
- index.html
- style.css
- script.js

## Set the birthday date and time
Open `script.js`. The first lines hold BIRTHDAY_TARGET. Format: "2026-12-25T00:00:00+08:00"
(+08:00 is Philippine Time). Save, upload, done.

## Test it before the real day
Set the date to 2 minutes from now, open the page, watch it count down, and the button appears at zero.
A past date shows the surprise button straight away.

## Upload to GitHub Pages
1. Create a repo (or open your existing one) and upload all files to the root.
2. Settings > Pages > Source: "Deploy from a branch", branch main, folder /(root).
3. Open https://YOUR-USERNAME.github.io/YOUR-REPO/
